6: in second screen 'delete All' button didnt wipout everyting 
Delete All already “sends a note.” Pack never reads that note, so nothing gets wiped.

You already started the fix in index.tsx: you read clear, but you do not use it yet. The useEffect still only loads saved data.

How to debug this
Do not guess. Follow the tap.

Find the button: Delete All → onPress={deleteAll} in checkList.tsx.
Read deleteAll. Ask: does this function empty tripName / items, or delete storage? Right now it does neither. It only navigates:

checkList.tsx
Ln 25–28
router.replace({
  pathname: '/',
  params: { clear: '1'},
});
That means: “go to Pack, and pass clear=1.”           // clear: '1' is just a flag — a small note Pack can read. 

Go to Pack (index.tsx) and search for clear. You now have:

index.tsx
Ln 14–15
const params = useLocalSearchParams<{clear?: string | string[]}> ();
const clear = String(params.clear ?? '');
But clear is never used. The load effect always does this:


index.tsx
Ln 25–35
  async function loadTrip() {
    const raw = await AsyncStorage.getItem(STORAGE_KEY);
    if (!raw) return;
    // ... puts the old trip back on screen
  }
  loadTrip();
}, []);
[] means this runs once when Pack first opens, not when you come back from Delete All.

Optional check: add console.log('clear param', clear) in Pack, tap Delete All, watch the terminal. You should see '1'. If the list is still there, you know: the flag arrived, the wipe never ran.
Why it looks like “nothing happened”
The app keeps the trip in two places:

Place	What it is
React state (tripName, items)
what you see on screen
AsyncStorage (packing-trip)
what is saved after Add / Delete
Delete All does not clear either one. Pack is still in memory with the old list. If Pack reloads later, it reads AsyncStorage and the old trip comes back.

So the bug is not the alert. The alert works. The missing piece is: Pack must wipe when clear is '1'.

Solution
When clear === '1':

Empty the screen: trip name, input, items, packed.
Delete saved data: AsyncStorage.removeItem(STORAGE_KEY).
Go to / without the flag, so it does not keep wiping.
Replace your current useEffect with:

useEffect(() => {
  let cancelled = false;
  async function syncTrip() {
    if (clear === '1') {
      setTripName('');
      setNewItem('');
      setItems([]);
      setPacked([]);
      await AsyncStorage.removeItem(STORAGE_KEY);
      if (!cancelled) {
        router.replace('/');
      }
      return;
    }
    const raw = await AsyncStorage.getItem(STORAGE_KEY);
    if (cancelled || !raw) return;
    const data = JSON.parse(raw);
    setTripName(data.tripName ?? '');
    setItems(data.items ?? []);
    setPacked(data.packed ?? []);
  }
  syncTrip();
  return () => {
    cancelled = true;
  };
}, [clear]);
Two important details:

[clear] — run again when Delete All sends clear: '1', not only on first load.
data.items ?? [] — use an empty array, not ''. .map() needs an array.
Leave checkList.tsx as it is. That screen only sends the signal. Pack is where the data lives, so Pack is where you wipe.

How you’ll know it worked: add items → CHECK LIST → Delete All → confirm → Pack is empty, and it stays empty if you leave the app and open it again.
